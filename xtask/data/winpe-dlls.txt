# DLLs that DISM Pro executables may import and still start in WinPE (doc 04 §4, `xtask pe-compat`).
# One lower-case name per line; a trailing `*` matches a prefix. `#` starts a comment.
#
# Policy: this list only grows with evidence. Each addition cites its source (Microsoft's
# "WinPE: Add packages (Optional Components Reference)" or an ADK file listing) in the PR
# that adds it. CI checks every entry except API sets against base WinPE's System32, amd64 and
# arm64, from the ADK's winpe.wim (`xtask pe-compat --winpe-files`, ffi-check job). "base WinPE"
# below means that check passed for ADK 10.1.26100.9457.
#
# Seed: what an empty Rust std binary with the static CRT (.cargo/config.toml) imports.
kernel32.dll                        # core Win32 (base WinPE)
ntdll.dll                           # NT native API used by std (base WinPE)
bcryptprimitives.dll                # std random numbers, ProcessPrng (base WinPE)
api-ms-win-core-synch-l1-2-0.dll    # std locks (WaitOnAddress); API set the loader resolves, no file to check
# Added with the CLI (roadmap 2.5): registry/token APIs and the DISM API.
advapi32.dll                        # registry + token APIs, windows-sys (base WinPE)
dismapi.dll                         # DISM API (base WinPE)
